# 90-second demo script (draft)

**0:00–0:10 — Problem.** "Group purchases die in the chat: nobody decides, nobody wants to front the money."

**0:10–0:25 — Goal and preferences.** In the group thread: "@huddle birthday gift for Dana, $150 total." Each person replies with one preference.

**0:25–0:40 — Options and vote.** Huddle posts three options with reasons. Everyone replies with a number; the tally updates live; the winner is announced.

**0:40–0:60 — Mandate.** Huddle posts the card: item, merchant, $ cap, each share, expiry. Show one decline sending the group back to new options (optional if time is short), then everyone approves.

**0:60–0:80 — Checkout.** "Buying now…" then the confirmation, order status, and who owes whom. Call out that the cap and merchant are enforced by the mandate before any Visa call.

**0:80–0:90 — Close.** Built on Photon Spectrum and Visa Intelligent Commerce. State plainly whether checkout ran on the Visa sandbox or the mock.

Backup: `npm run simulate` shows the same flow in a terminal.
